Разверни у меня на этом компьютере проект Jarvis — личный ассистент на Claude
(репозиторий https://github.com/argokz/jarvis, ветка main). Код уже написан и протестирован в облаке.
Твоя задача — поставить, настроить и проверить его здесь, ничего не переписывая без причины.

## Что это за проект (прочитай README.md после клонирования)
- `jarvis/` — ядро на Python: FastAPI + Claude Agent SDK, память в Obsidian-vault,
  Telegram-бот, голосовой WebSocket, подтверждения, push через ntfy.
- `jarvis/voice_client.py` — голосовой клиент для ПК (wake word «Hey Jarvis», микрофон, озвучка).
- `app/` — клиент на Vue 3 + Tauri 2 (окно для Windows/macOS, APK для Android, веб-версия на /app/).

## Шаги
1. Определи ОС и проверь инструменты: git, Python 3.12+ и uv, Node 22+, Claude Code CLI (`claude`).
   Rust (rustup) нужен только для сборки окна Tauri — если его нет, скажи мне и пропусти этот шаг.
   Недостающее не ставь молча: перечисли, что нужно, и спроси.
2. Спроси меня, куда клонировать (по умолчанию `D:/projects/jarvis` на Windows, `~/projects/jarvis`
   иначе), и склонируй.
3. Спроси, есть ли у меня уже Obsidian-vault. Если есть — путь к нему пойдёт в `JARVIS_VAULT`
   (ядро только добавит недостающие папки 00_Inbox, 10_Projects, … и ничего не удалит).
   Если нет — используй папку `vault` рядом с проектом.
4. `uv sync --extra voice`, затем `uv run --extra voice pytest -q` — должно быть 38 passed.
5. Создай `.env` из `.env.example`. Сам заполни только несекретное: `JARVIS_VAULT`, `JARVIS_DB`,
   `JARVIS_API_TOKEN` (сгенерируй: `python -c "import secrets; print(secrets.token_hex(32))"`),
   `JARVIS_OPEN_ROOTS` (спроси, в каких папках разрешить искать и открывать файлы).
   Ключи (`ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`, `YANDEX_SPEECHKIT_API_KEY`, `GITHUB_TOKEN`)
   я впишу в файл сам — не проси вставлять их в чат и не выводи содержимое `.env`.
   Подожди, пока я скажу, что ключи вписаны.
6. Запусти ядро: `uv run uvicorn jarvis.api:app --host 127.0.0.1 --port 8000`
   (в фоне или отдельном терминале). Проверь `GET http://127.0.0.1:8000/health` и
   `POST /chat` с заголовком `Authorization: Bearer <JARVIS_API_TOKEN>` и текстом
   «Какие проекты есть?». Покажи ответ и строки лога ядра с ошибками, если есть.
7. Веб-клиент: `cd app && npm install && npm test && npm run build`. После этого ядро раздаёт
   его на http://127.0.0.1:8000/app/ — открой адрес и скажи мне войти с токеном.
8. Голос на ПК: `uv run --extra voice python -m jarvis.voice_client --list-devices`, покажи список
   микрофонов, помоги выбрать (`--device N`), затем запусти клиент. Я проверю «Hey Jarvis» сам.
   Если SpeechKit вернёт ошибку формата/голоса/частоты — параметры в `jarvis/speech.py`
   и `.env` (YANDEX_SPEECHKIT_*) брались без доступа к документации, сверь их с
   https://yandex.cloud/ru/docs/speechkit и поправь.
9. Окно Tauri (если есть Rust): `cd app && npm run tauri build`; покажи путь к установщику.
10. Доступ с телефона: если установлен Tailscale — `tailscale serve --bg 8000` и покажи HTTPS-адрес.
    Если нет — объясни, что поставить (на ПК и на телефон; на Huawei — APK).
11. Спроси, нужен ли автозапуск ядра при входе в Windows; если да — предложи задачу в
    Планировщике заданий (без прав администратора, если можно) и создай только после моего «да».

## Правила
- Работай по шагам и коротко отчитывайся после каждого: что сделано, что проверено.
- Не коммить и не пушь, пока я не попрошу. `.env`, `data/`, `vault/` уже в .gitignore.
- Если тест или проверка падают — сначала разберись в причине и покажи вывод, не обходи проверку.
- Найдёшь ошибку в коде — исправь минимально, добавь тест и скажи мне.
