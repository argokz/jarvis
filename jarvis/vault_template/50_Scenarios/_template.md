# Шаблон сценария

Скопируйте заметку под своим названием — оно и будет названием сценария. Заметки, чьё имя
начинается с «_», сценариями не считаются.

Сценарий запускается фразой («Клод, я дома»), по времени, кнопкой в приложении или просьбой
«запусти сценарий …». Фраза сверяется целиком и до модели, поэтому срабатывает сразу.

## Шаги

| Шаг | Что делает |
|---|---|
| `on: Торшер`, `off: {name: Свет, area: Зал}` | включить, выключить устройство дома; название — как в Home Assistant |
| `home: {tool: HassLightSet, name: Торшер, brightness: 30}` | любой другой инструмент дома |
| `volume: 30`, `volume: mute`, `volume: unmute` | громкость компьютера |
| `media: pause` | плеер: `play`, `pause`, `toggle`, `next`, `previous`, `stop` |
| `music: моя волна`, `music: {query: джаз, where: station}` | включить музыку на компьютере или на Станции |
| `youtube: лофи радио` | найти и открыть видео на YouTube в браузере |
| `open: https://music.yandex.ru` | открыть сайт |
| `notify: Пора на встречу` | показать уведомление на экране |
| `timer: 10m` | таймер: `90s`, `10m`, `1h30m`; число без единицы — минуты |
| `alarm: "07:00"`, `alarm: {at: "07:00", repeat: weekdays}` | будильник |
| `remind: {at: "08:00", text: выпить таблетки}`, `remind: {in: 30m, text: …}` | напоминание |
| `say: С возвращением` | произнести фразу |
| `ask: Какие задачи открыты в проектах?` | поручить агенту и произнести его ответ |

Шаги выполняются по порядку. Если один не удался, остальные всё равно выполнятся, а в конце
ассистент скажет, что не получилось.

## Расписание

`schedule: "07:30"` — каждый день; `"пн-пт 07:30"`, `"сб,вс 10:00"`, `"будни 08:00"`; несколько
времён — списком. Если в это время ядро не работало дольше десяти минут, запуск пропускается.
