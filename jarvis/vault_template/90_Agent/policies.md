# Политики агента

Этот файл агент читает, но менять не может (запрещено в коде ядра).

## Без подтверждения
- Чтение и поиск по vault.
- Заметки в `00_Inbox/`, записи в `40_Journal/`, память в `90_Agent/memories/`.
- Обновление заметок проектов в `10_Projects/` (задачи, журнал, last_touched).

## Только вручную (агенту недоступно на этапе 1)
- Любые действия вне vault, shell, git push, деплой.
- Изменение этого файла.

## Чувствительные проекты
Проекты с `sensitive: true`: в LLM — только код и синтетические данные, никаких реальных
персональных/медицинских данных.
